## 信任模型（K7 摘要）

```
插件包（zip）──不可信──► 安装时校验（D24）──► iframe CSP 运行（D25）
                              │                        │
                              ▼                        ▼
                     权限白名单声明（FR-W7）    数据/动作通道执行（D26/D27）
                     apis / credentialKinds     服务端把关 + 审计日志
                     / actions
```

| 边界 | 规则 | 用户可见交互 |
|---|---|---|
| 包安全（D24） | entry 限包内相对 ESM 路径；拒绝对路径/穿越/隐藏段；条目数与解压体积限额 | 安装报错逐条列出 |
| 运行隔离（D25） | iframe CSP：独立源、禁脚本逃逸、禁顶层导航；宿主给最小 sandbox | 组件即 iframe 面板 |
| 数据（D26） | `capabilities.data` 经宿主代取；越权（未白名单资源/凭证类型）即拒 | 错误显式提示 |
| 动作（D27） | `actions` 白名单 → 服务端固定 registry 执行 + **审计日志** | 无直接 API；动作结果回组件 |
| 凭证（SEC3） | 解密仅在服务端 connector；`credentialKinds` 限定类型 | 配置里只见 secret 占位 |
| 生命周期 | 禁用：实例保留不可用；卸载：删文件+登记，业务数据不动 | 确认弹窗点名后果 |

## 用户旅程（含错误态）

| 步骤 | 成功 | 失败 |
|---|---|---|
| 上传 zip | FileInput/拖放 → 安装 | 校验拒绝（manifest 非法/越界/超限/类型占用/版本不兼容）→ 消息条逐条 |
| 启用 | manifest 并入选择器 | — |
| 添加实例 | 同内置组件 | — |
| 运行取数 | 数据通道按白名单放行 | 越权/超时 → 显式错误（不空白，D32 原则） |
| 执行动作 | registry + 审计 | 未白名单动作 → 拒绝并提示 |
| 卸载 | 确认 → 删文件+登记 | 确认弹窗取消则保留 |
