## Q23a · 页面走查条目

### ISS-1 页面 CRUD 全链路无错误处理【逻辑 · P1】

- **位置**：工作台页 → 新建页面 / 页面设置 / 删除此页 / 上移·下移（`App.tsx`）
- **现象**：`addDashboard / savePageSettings / removeActive / moveActive` 均 `await api.*` 且无 try/catch —— 网络失败或服务端报错时为未处理 Promise 拒绝：UI 无任何提示，输入内容与操作意图丢失。
- **复现**：断网（或服务端 500）→ 点「新建页面」→ 无任何反馈；控制台报 unhandled rejection。
- **期望**：失败提示（WbAlert，参错误态规范）+ 可重试；至少不静默。
- **证据**：`p04-workspace-overview`（同屏所有受影响按钮）
- **建议**：四处操作统一 try/catch → 页级错误条；归 Q24 修复批。

### ISS-2 空输入静默无反馈（新建页面 / 页面设置）【逻辑 · P1】

- **位置**：工作台页 → 「新页面名」输入 + 「新建页面」；页面设置弹窗「名称」+「保存」
- **现象**：`addDashboard` 对空名 `if (!title) return;` 直接返回 —— 按钮不禁用、点击无反应、无提示；页面设置同理。
- **复现**：不输入任何字符 → 点「新建页面」→ 按钮有按压反馈但一切未发生。
- **期望**：按钮 `disabled`（与 Todo「添加」等一致），或点击给内联校验提示。
- **证据**：`p04-workspace-overview`、`p08-page-settings`
- **建议**：统一表单校验策略；归 Q24。

### ISS-3 活动页签不持久化，刷新回到第一个页签【逻辑 · P1】

- **位置**：工作台页 → 页签栏
- **现象**：`activeId` 仅存内存（`useState`），刷新/重登后 `refresh()` 回填第一个页签；页面身份不进 URL，无法深链/收藏某页。
- **复现**：切到任意非首个页签 → F5 → 回到「首页」。（历史自动化也曾两次踩中此坑误删 fixture）
- **期望**：活动页持久化（URL query 或 localStorage），刷新停留在原页。
- **证据**：`p04-workspace-overview`（页签区）
- **建议**：`?page=<id>` 同步；归 Q24。

### ISS-4 布局保存失败提示「稍后自动重试」，实际无重试调度【逻辑 · P1 · 文案与行为不符】

- **位置**：编辑态 → 布局自动保存（`Board.tsx` flush 失败分支）
- **现象**：失败后 `setSaveError("布局保存失败，稍后自动重试")` 并保留 pending，但**没有任何定时器调度重试**（代码注释：keep pending for next change to retry）——只有下一次布局变更才重试，用户不再动就永远停在失败态。
- **复现**：编辑态拖动组件时服务端 500 → 出现错误条 → 停止操作 → 无任何重试发生。
- **期望**：真·定时重试（退避），或文案改为「保存失败，再次拖动组件时重试」。
- **证据**：`p09-edit-mode`
- **建议**：补退避重试计时器；归 Q24。

### ISS-5 「上移/下移」边界不禁用，首/末页点击静默无效【逻辑 · P2】
- **状态**：✅ **已修（Q24c）** —— 首行禁用「上移」、末行禁用「下移」

- **位置**：工作台页 → 工具栏「上移」「下移」
- **现象**：`moveActive` 越界 `return;` —— 按钮永远可用，处于首/末页时点击无任何反应（无 disabled、无提示）。
- **期望**：首行禁用「上移」、末行禁用「下移」（与「删除此页」的条件渲染同风格）。
- **证据**：`p06-workspace-tabbar`
- **建议**：按 `activeId` 与序号计算 disabled；归 Q24。

### ISS-6 「删除最后」语义错位：删的是"最后一个"而非"选中的"【逻辑 · P1】

- **位置**：编辑态 → 工具栏「删除最后」（`BoardToolbar`）
- **现象**：点击即删除 `getGridItems()` 的最后一项，画布没有「选中组件」概念 —— 用户想删 A，可能删掉 Z。布局编辑内的移除按 D31 豁免确认，目标不可控 + 无确认 = 误删布局成本高（虽不动业务数据）。
- **期望**：改为逐组件删除入口（WidgetChrome 上的「移除」按钮，点谁删谁），或选中态 + 删除选中。
- **证据**：`p10-edit-toolbar`
- **建议**：Q24 重设计（与 WidgetChrome 合并考虑）。

### ISS-7 移动端无「数据管理」入口，与 FR-D2 定位不一致【逻辑 · P1】
- **状态**：✅ **已修（D41，方案 A）** —— 「数据管理」放开移动端（数据操作 ≠ 布局编辑）；编辑布局/插件管理仍桌面专属

- **位置**：工作台页 → 头部（375px 视图）
- **现象**：「编辑布局/数据管理/插件管理」均 `isDesktop` 才渲染；D10 允许移动端"浏览 + 组件内操作"，组件内「筛选」（标签）可点，但**创建标签/管理数据**必须回桌面端 —— 同一能力在移动端断链。
- **期望**：至少「数据管理」移动端可达（数据操作非布局编辑，不违反 D10）；插件管理可维持桌面专属。
- **证据**：`p12-mobile-browse`
- **建议**：放开数据管理的 isDesktop 限制；归 Q24（涉及 D10 边界解释，需拍板）。

### ISS-8 登录页缺品牌图标，与头部识别不一致【样式 · P2】
- **状态**：✅ **已修（Q24c）** —— 登录页标题前加 favicon 图标（与头部一致）

- **位置**：登录页 → 标题
- **现象**：头部有 favicon 图标 + 「个人工作台」，登录页仅纯文字标题。
- **期望**：登录页标题前加同一图标（复用 `/favicon.svg`）。
- **证据**：`p01-login` vs `p05-workspace-header`
- **建议**：归 Q24 样式批。

### ISS-9 「忘记口令？」是可点击 Text，键盘/读屏不可达【逻辑 · P2 · 无障碍】
- **状态**：✅ **已修（Q24c）** —— 改 UnstyledButton（可聚焦、Enter/Space 触发、aria-expanded）

- **位置**：登录页 → 「忘记口令？」（`LoginPage.tsx`）
- **现象**：`<Text onClick>` 非按钮语义 —— 不可 Tab 聚焦、Enter/Space 不触发、无 `aria-expanded`。
- **期望**：`<button>`（或 Mantine Button subtle）+ `aria-expanded={hintOpen}`。
- **证据**：`p02-login-hint`
- **建议**：归 Q24 无障碍批。

### ISS-10 登录错误仅通栏提示，无字段级定位【逻辑 · P2】
- **状态**：✅ **已修（Q24c）** —— 失败后清空口令并聚焦口令框（用户名保留）

- **位置**：登录页 → 错误态
- **现象**：认证失败仅顶部 WbAlert 通栏文本；不聚焦出错字段、不清空口令框；无 Caps Lock 提示。
- **期望**：错误后聚焦口令框 + 清空口令（用户名保留）；可加 Caps Lock 提示。
- **证据**：`p03-login-error`
- **建议**：归 Q24。

### ISS-11 编辑态无操作引导（手势/手柄不可见性）【样式 · P2】

- **位置**：编辑态 → 画布
- **现象**：进入编辑态后无任何提示说明"拖动移动 / 右下角手柄缩放 / hover 才显手柄"；缩放手柄 autohide（D12 实测结论），新用户发现成本高。看板组件内部有编辑态提示，全局画布反而没有。
- **期望**：编辑态顶部一次性提示条（可关闭）或空态引导。
- **证据**：`p09-edit-mode`、`p11-edit-hover-handle`
- **建议**：归 Q24。

## Q23b · 组件走查条目

### ISS-12 加载态表达不统一【样式 · P2】

- **位置**：各组件加载/探测态
- **现象**：同一「取数中」语义三种表达——「加载中…」（todo/rss/custom-api 小字）、「探测中…」（launcher/monitor/opencode 小字）、iframe 居中 Loader；位置（行内/居中）与样式各异。
- **期望**：统一加载态规范（文案 + 位置 + 样式，可复用 `.wb-loading`）。
- **证据**：`c-todo` / `c-monitor` / `c-iframe` 对比。

### ISS-13 看板归档后无法恢复（死路径）【逻辑 · P1】

- **位置**：看板组件 → 卡片「归档」/ 头部「已归档 N」
- **现象**：归档卡片从列中移除（`cardsOf` 过滤 `archived`），唯一可「取消归档」的入口在**卡片编辑弹窗**，而归档卡片已不可点击 —— 取消归档为不可达死路径；头部仅计数不可点。
- **复现**：卡片编辑 →「归档」→ 卡片消失 → 无任何入口找回。
- **期望**：「已归档 N」可点开归档列表（恢复/彻底删除）。
- **证据**：`c-kanban`
- **建议**：Q24 优先（功能性缺陷）。

### ISS-14 Todo 默认过滤下完成后无法撤销【逻辑 · P1】

- **位置**：Todo 组件 → 行勾选框（`filter=open` 默认）
- **现象**：勾选完成 → 该行立即从列表消失（未完成过滤）；无「显示已完成」运行时开关；详情弹窗只有状态文本无操作 —— 误勾无法在组件内撤销。
- **期望**：完成时短暂可撤销（undo）/ 运行时切换显示已完成 / 详情弹窗提供状态切换。
- **证据**：`c-todo`
- **建议**：Q24。

### ISS-15 清单名映射不一致（life/生活）【逻辑 · P2】
- **状态**：✅ **已修（Q24c）** —— 映射表与 manifest 选项同源（widget-registry.listLabel，含 life→生活），Todo 头部/详情/数据管理徽标统一

- **位置**：Todo 头部标题、详情弹窗、数据管理清单徽标
- **现象**：manifest 清单选项为 收件箱(inbox)/工作(work)/**生活(life)**，但显示映射表是 inbox/work/**home/personal** —— 选「生活」的组件头显示「Todo · life」；数据管理徽标直接显原始键名（如 `inbox`）。
- **期望**：映射表与选项同源（建议清单名映射下沉为共享常量/表），未知键回落原文。
- **证据**：`c-todo` vs `widget-registry` 配置选项。
