## 2. 远期方向（公网化 / 多用户，D1/D9）

**触发条件：需要公网访问或多人使用时启动。** 届时必须完成（SEC6）：

- HTTPS 强制、速率限制、审计日志、防点击劫持；
- 多用户语义落地（user 表、session 归属、数据隔离）；可选 RBAC、OAuth/SSO、二次验证（SEC7）；
- PostgreSQL 迁移（Drizzle schema 已预留）；
- 现有服务深度集成（Immich/n8n 等 connector）、Webhook 接收（FR-E6）、组件间联动。
