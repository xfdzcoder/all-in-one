# 产品需求规格 v1.0（冻结）

> 状态：**冻结**（产品范围确认，2026-09-28）。变更须走 [02-decisions.md](02-decisions.md) 决策流程。
> 标记：**【必须】** 首版必备 · **【应该】** 重要可稍后排 · **【暂不考虑】** 本期明确不做 · **【待确认】** 需拍板

## 1. 项目定位

### 1.1 项目目标

- **G1**：统一的自托管个人工作台，多页面自由编排组件，取代"三个软件拼一页"（Homarr / DoBase / Glance 的核心能力融合）的使用方式。【必须】
- **G2**：Widget 为核心抽象，具备统一的元数据、配置、数据、交互契约；新增组件不改核心。【必须】
- **G3**：组件可操作、可配置数据源，而非纯展示。【应该】
- **G4**：桌面与手机均为一等体验。【必须】
- **G5**：为多用户与公网暴露预留架构空间（不实现）。【必须（设计约束）】

### 1.2 非目标（本期明确不做）

| 非目标 | 说明 |
|---|---|
| 多用户/多租户实现 | 仅预留扩展点（D9） |
| 公网部署能力（HTTPS 强制/域名/限流/审计落地） | 安全设计上不堵死，实现排后 |
| 微服务、分布式、集群、高可用 | 单机 Docker Compose |
| 服务端渲染（SSR） | SPA 足够，登录墙下无 SEO 需求 |
| 完整邮件客户端（回复/归档/删除/标记） | 邮件只读（D3） |
| 组件商店/插件市场 | 本期只要机制不要市场 |
| 与 Homarr / DoBase / Glance 的数据迁移 | 自研替代，无迁移需求 |
| 组件间联动/事件总线 | 过度设计 |

### 1.3 概念模型与数据归属原则

**三层模型：**

```
Workspace（空间/工作台）      ← 业务数据的属主
  │                             Todo、RSS 源与已读状态、未来的 Kanban、
  │                             凭证库、第三方连接配置
  ├── Dashboard / Page（页面）← 只拥有布局
  │     ├── Widget 实例        组件位置、尺寸、组件实例配置（视图参数）
  │     └── Widget 实例
  └── Dashboard / Page（页面）
        └── Widget 实例        ← 同一数据的另一个视图
```

**归属原则：**

1. **Workspace 拥有数据**；删除页面/删除组件**绝不删除业务数据**；
2. **Dashboard 只拥有布局**（widget 的 x/y/w/h + 配置）；
3. **Widget 实例 = 视图 + 交互**，其配置只引用数据（如 `todoListId`、`feedIds`、过滤器），不内嵌数据；
4. 凭证库挂在 Workspace 层，与任何页面无关（SEC3）。

**收益：** 同一 Todo 列表可被多个页面的组件展示且实时一致；布局随便改数据无损；数据表带归属字段后未来多用户 = 每用户一个 Workspace，无需重构。

**命名约定：** 文档与代码统一 `Workspace > Dashboard > Widget`；口语"工作台"= 项目整体或 Workspace 顶层，以文档为准。

**首版简化：** 单用户下 Workspace 唯一，仅作数据归属边界存在，**无多 Workspace 切换 UI**。

### 1.4 用户使用场景

| # | 场景 | 优先级 |
|---|---|---|
| S1 | 打开"首页"工作台：一眼看到常用服务入口与存活状态、待办、未读信息流 | 【必须】 |
| S2 | 在"开发"工作台聚合自定义 API、服务器指标等（排后组件就位后） | 【应该】 |
| S3 | 拖拽重排组件、调整大小、添加/删除组件，刷新浏览器后布局保留 | 【必须】 |
| S4 | 在手机上舒适浏览工作台：布局自动适配、可滑动查看、可操作组件内容 | 【必须】 |
| S5 | 在 Todo 组件内直接勾选完成任务，不跳转其他应用 | 【必须】 |
| S6 | 在 RSS 组件内点开文章摘要/跳转原文 | 【必须】 |
| S7 | 用 iframe Widget 快速嵌入 Portainer 等已有服务页面作为过渡 | 【必须】 |
| S8 | 配置自定义 API Widget，展示任意接口数据 | 【必须】 |
| S9 | （二期）安装/启用一个第三方 Widget 插件，像内置组件一样使用 | 【应该】 |

### 2.3 首版组件范围（冻结，D8）

**首版（In Scope）：**

| 组件 | 范围说明 | 优先级 |
|---|---|---|

| # | 旅程 | 验收要点 |

| J1 | 首次部署 → 初始化账号 → 登录 → 默认"首页"（预置示例组件） | 空状态引导清晰 |
