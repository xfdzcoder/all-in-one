# 视觉设计走查（Q19a）· 基线审计

> 2026-09-30，对**每一个页面 / 每一个组件**截图走查（`apps/web/scripts/capture-design.mjs` 采集，
> 基线图见 [baseline/](baseline/)，按 `gs-id` 精确锚定命名）。对照成熟体系（Material Design 3 /
> Apple HIG / Radix Colors / 8pt 网格 / 模块化字阶）给出诊断与修复计划。
> 客观底线：`verify-dark.mjs`（WCAG AA 对比度）保持 0 失败；NFR2 触控 ≥44px 不回退。

## 一、总评

功能与信息架构扎实，视觉处于「能用但不精致」：**深色体系刚统一（第 28 轮）但组件层几乎无设计语言**
——无卡片容器、间距无节奏、按钮层级混乱、错误态表达不统一。好消息是问题高度收敛于「令牌层 + 容器层」，
一旦补齐 Card/间距/按钮三件套，观感会整体跃升（受限 JSX 模板渲染出的组件就是现成的正面样例）。

**问题分级**：P0 视觉硬伤 4 项、P1 一致性/层级 5 项、P2 打磨项 8 项。

## 三、P1 —— 层级与一致性

| # | 问题 | 证据 | 修复方向 |
|---|---|---|---|
| P1-1 | **按钮层级混乱**：低频破坏性「删除此页」红底实心过重；「新建页面」蓝底实心；「页面设置/上移/下移」描边；「刷新」是纯文字链接；「添加/订阅/安装」禁用态发灰无解释 | `02`、`03`、`11` | 按钮语义四档：主（蓝实心，每屏 ≤1）/ 次（描边）/ 幽灵（刷新、详情）/ 危险（红，仅破坏操作，且不与主操作并排抢眼）；尺寸统一 xs/sm 两档 |
| P1-2 | **表单控件滥用**：看板列标题是常驻输入框（待办/进行中像表单项）；RSS 订阅行（标题+URL+订阅）常驻占头部；工具栏"新页面名+新建页面"输入按钮连排 | `15`、`11`、`02` | 列标题改纯文本 + 点击/双击进入编辑；订阅入口收进"+"弹层；页面新建收进页签栏尾"+"" |
| P1-3 | **错误/警告表达不统一**：邮件=橙色通栏、RSS=黄色小字、JSX=红色 Alert、应用入口=无错误态 | `16`、`11`、`18` | 统一错误组件规范：内联 Alert（图标+色+文案+可关）三档尺寸；警告黄、错误红、信息青 |
| P1-4 | **文案硬伤**：登录页泄露实现细节（"首次部署请设置 ADMIN_PASSWORD 环境变量（D17）"——D17 是内部决策号）；Todo 头部显示原始 `inbox`；时间全部绝对时间 | `01`、`10`、`19` | 登录页提示改人话并仅在需要时显示；清单名映射（inbox→收件箱）；时间改相对（"2 小时前"+悬浮绝对） |
| P1-5 | **头部与页签无识别性/无收纳**：品牌纯文字；40+ 页签换 4 行占满顶部（真实场景少页签，但缺弹性） | `02` | 头部加图标/版本徽标；页签改横向滚动 + 溢出"更多"菜单；工具栏与页签合并为一行 |

## 四、P2 —— 打磨项

1. 间距节奏：全面归一 8pt（4/8/12/16/24/32）；卡片内边距 16、行距 12。
2. 字号阶梯：12/13/14/16/20/26 模块化；组件标题 14 semibold、数值 20–26、辅助 12。
3. 圆角/边框：6/10/14 三档；边框统一 `rgba(255,255,255,.08)`；深色层级用表面明度（Radix 式 1–12 级）而非投影。
4. hover/焦点态：卡片 hover 微亮 + 边框提亮；焦点环统一（现在仅浏览器默认蓝框）。
5. stat 预设重设计（P0/P2 之间）：`17-widget-customapi-stat` 现为"字段表 + 原始 JSON dump"，应改成标签在上/数值大的统计卡（对齐监控组件的 MetricCard），嵌套数组转列表或省略。
6. 占位组件（欢迎）：渐变蓝与其他组件语言脱节 → 收敛为主题色 + 图标 + 简洁标题；`13` 指标卡（在线服务 2/3）同理做成迷你 stat 卡。
7. iframe 面板：加边框/加载态；URL 徽标样式（现为大写等宽风格）统一为小号次级文本。
8. 详情弹窗：JSON 用等宽字体 + 复制按钮；插件管理空态加说明与拖放区（`08` 现为空 bullet）；确认弹窗标题改情境化（"删除页面？"）+ 图标。

## 六、修复计划（映射 Q19）

- **Q19b · 令牌 + 容器**（修 P0-1/P0-2/P0-4 + P2-1/2/3）：Mantine theme 定制（色阶/间距/字阶/圆角/边框）→ WidgetCard 统一容器与 header → 移动端单列全宽 → JSX 允许名单补排版属性。
- **Q19c · 组件样式统一**（修 P1-1/2/3 + P2-5/6/7）：按钮四档、错误态统一、看板列头/RSS 订阅行/工具栏收纳、stat 预设与占位卡重设计、iframe 面板。
- **Q19d · 文案与细节**（修 P1-4/5 + P2-4/8）：登录页提示、清单名映射、相对时间、页签收纳、hover/焦点态、弹窗细节。
